## Context

目前 `TabState` 记录活动面板、预览位列表及选中预览层；`PreviewEditor` 另有内容、编辑会话、光标和滚动缓存。tab 恢复、槽切换、窗口回焦分别处理焦点，细粒度焦点（内容、大纲、编辑器）没有统一快照。缓存可能因文件变化或资源预算失效，因此视觉恢复与最终内容就绪是两个阶段。

## Goals / Non-Goals

**Goals:**
- 三条切换路径遵守相同的目标状态：工作区、活动槽、模式、可见内容与焦点一致。
- 有效缓存先展示保留画面；异步重建完成后恢复光标、选区和阅读位置。
- 保留目录面板键盘切槽时的目录焦点和选中预览层。

**Non-Goals:**
- 持久化到磁盘或跨进程重启恢复。
- 在文件已变化、缓存失效或 PDF 资源被回收时保证零延迟。
- 改变未保存修改的确认流程或目录选中即预览的语义。

## Decisions

1. **以稳定身份保存恢复快照。** 工作区保存活动面板及焦点目标，预览槽按 `(workspaceId, slotId)` 保存模式、编辑选区、滚动、大纲和 PDF 阅读位置。焦点目标用受限枚举表达（目录、预览内容、编辑器、Markdown 大纲、PDF 大纲、终端），不保存 DOM 元素引用。这样组件重建后仍可解析目标；仅查询当前 DOM 焦点无法跨卸载恢复。
2. **切换前同步拍快照，切换后按顺序恢复。** 先确定目标身份与可见层，再激活保留内容和模式，最后在 Svelte 更新完成及必要资源就绪后聚焦目标并恢复位置。延迟任务带目标身份和恢复代次；过期回调不得覆盖更新的切换。窗口失焦只保存当前焦点目标，回焦复用同一恢复入口，但不重置内容或编辑模式。
3. **预览层服从目标焦点。** 目录焦点允许保留其 `selectionPreview`；显式聚焦预览内容或恢复 preview 焦点时清除遮挡层。普通焦点移动仍不改变目录选中预览。进入槽标签触发的切槽沿用显式激活语义；从 current 面板的键盘切槽仍保留预览层。
4. **保留画面与最终状态分阶段。** 有效槽 DOM 和编辑会话立即复用；缓存失效时先保留安全占位，再加载并应用快照。仅在文件身份仍一致时恢复编辑选区；位置超出新内容范围时夹取到有效范围。资源回收后的 PDF 恢复沿用其重建流程。

## Risks / Trade-offs

- [异步渲染或旧焦点回调覆盖当前目标] → 在每次切换递增恢复代次，回调检查工作区、槽和路径。
- [编辑器模式与大纲焦点相互抢夺] → 将焦点作为单一目标，并在内容/模式就绪后执行一次最终聚焦。
- [文件变化导致旧位置无效] → 核对文件身份并夹取位置；不恢复过期内容快照。
- [增加快照字段与缓存生命周期复杂度] → 复用现有缓存管理器和稳定 ID，仅保存必要的可序列化状态。

## Migration Plan

先补状态类型和统一恢复入口，再接入 tab、槽和窗口路径，最后补各内容类型的焦点及位置恢复。无持久数据迁移；回退可移除新增协调逻辑并保留现有缓存。
