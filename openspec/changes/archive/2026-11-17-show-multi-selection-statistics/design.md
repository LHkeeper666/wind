## Context

`DirectoryPanel.svelte` 已维护普通目录和项目树的多选状态，`getEntriesToOperate` 能解析选中根项及项目树排除路径。当前 `directory-dialogs.svelte.ts` 的 `toggleFileInfo` 仅用光标索引调用 `get_file_info`。`FileInfoPanel.svelte` 对单个目录使用 Rust `calculate_folder_size` 后台遍历和进度事件。

## Goals / Non-Goals

**Goals:**
- `i` 在存在显式选择时展示选集汇总；无显式选择时保留单项信息。
- 不阻塞 UI，持续显示进度，关闭面板即可取消；目录树排除项和重叠选择只统计一次。
- 统计口径明确：选中项数为用户选择的互不重叠根项数；递归文件数、目录数和总大小包括这些根项及其未排除的后代。

**Non-Goals:**
- 不改变现有单文件/单目录详情布局和目录大小语义。
- 不为归档内部条目或 FTP 路径增加本地文件系统递归统计。

## Decisions

### 选择解析放在前端，遍历放在 Rust 后台

目录面板复用 `getEntriesToOperate` 的选集解析，并把每个根项的路径及 `skip_rel_paths` 传给新的统计命令。Rust 在工作线程中遍历，直接累计文件数、目录数和字节数，定期发送进度。与前端逐项调用 `calculate_folder_size` 相比，单次遍历更容易取消、去重和保持一致的进度。

项目树选择根项的排除路径在遍历前归一化；嵌套或重复根项只统计一次。普通目录中未显式选择的光标项不混入选集。若没有显式选择，沿用现有 `get_file_info` 流程。

### 为每次计算使用独立请求标识

前端先注册进度监听，再启动命令。进度及完成事件携带请求标识；面板只接受当前请求的事件。关闭或切换内容时按请求标识取消并清理监听，避免旧计算覆盖新结果。进度值从零开始，结束时固定为最终值。复用现有目录大小遍历的节流、跳过不可访问项和不跟随链接的原则，但不复用以路径为唯一键的取消状态。

### 信息面板使用区分单项与汇总的数据模型

汇总视图显示 Selected items、Files、Directories、Size 和计算状态；单项视图仍显示路径、时间与属性。目录数包含选中的目录根项以及未排除的子目录；文件数包含直接选中的文件及目录内文件。无权限或遍历失败的部分显示“统计不完整”，避免将部分结果误认为完整值。

### 范围边界

普通本地目录与本地项目树支持汇总。归档浏览和 FTP 路径没有同样的本地遍历语义，维持其已有 `i` 行为；后续若要支持，需另行定义数据来源与统计口径。

## Risks / Trade-offs

- [大量目录遍历耗时] → 后台线程、节流事件、关闭即取消；UI 保持可操作。
- [项目树排除和重叠路径导致重复统计] → 按规范化路径处理根项和排除子树，并覆盖对应测试。
- [文件在计算中变化或无法访问] → 按遍历时状态统计，跳过失败项并标识结果可能不完整。
- [计算完成与关闭同时发生] → 使用请求标识过滤过期事件，取消与监听清理做成幂等操作。

## Migration Plan

无数据迁移。完成后通过 Svelte 类型检查、Rust 检查及选择/统计相关测试验证；回退只需撤销本次前后端改动。
