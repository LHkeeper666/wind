## Context

现有 `FileWatcher` 用于预览文件变更：它跳过目录、仅非递归监听一个父目录，并且全局只能存在一个 watcher。项目树需要独立的递归监听，且不能让构建输出的事件触发全树重建。

## Goals / Non-Goals

**Goals:**
- 自动更新项目树中受文件系统事件影响的已加载分支。
- 保留展开、选择和滚动状态；选中节点消失时回退到可见祖先。
- 根据项目树焦点确定新建和粘贴的目标目录。

**Non-Goals:**
- 不监听 FTP 项目树，不替换预览文件 watcher。
- 不自动刷新 `.git`、`target`、`node_modules` 的事件，也不隐藏它们。
- 不在每个 Tab 同时保留 watcher；仅监听当前可见项目树根。

## Decisions

### 独立的 `DirectoryWatcher`

Rust 新建目录 watcher，递归监听当前项目根并发射 `directory-changed` 事件。它与 `FileWatcher` 分离，避免预览文件切换停止项目树监听。切换项目模式、根目录或 Tab 时停止旧 watcher、启动新 watcher。

### 前端合并并局部刷新

`PanelLayout` 对事件按 250ms 去抖并传递受影响父目录给当前 `DirectoryPanel`。面板使所有受影响目录缓存失效；已加载节点重新读取子项，折叠或尚未读取的分支只失效缓存。刷新后按路径恢复展开与选择。

全树重建是备选方案，但会导致大项目闪烁并丢失局部加载优势，因此不采用。

### 默认忽略高频生成目录

Rust watcher 按目录段、大小写不敏感地过滤 `.git`、`target`、`node_modules` 中的事件。过滤不改变文件树可见性，用户仍可手动 `R` 或展开读取。

### 焦点目标目录

项目树提供 `getOperationDirectory()`：目录节点返回自身，文件节点返回父目录，树根返回根目录。`PanelLayout` 将此值用于新建与粘贴；重命名、删除、复制和剪切继续以所选节点为操作对象。

### 项目树惰性多选

项目树选择使用选中根路径集合和排除路径集合，不为高亮递归读取未展开目录。展开后的节点根据祖先选择和排除路径即时计算选中状态；复制、剪切和删除将排除路径作为相对路径传给传输后端，由后台递归操作时应用排除规则。

## Risks / Trade-offs

- [构建期间事件突发] → 250ms 去抖、目录去重并过滤高频生成目录。
- [重命名包含多个路径] → 同时失效事件中每个路径的父目录。
- [监听资源泄漏] → 所有模式/Tab 切换和组件销毁路径显式停止 watcher。
- [外部改动删除选择] → 回退到最近可见祖先而非保留失效路径。
