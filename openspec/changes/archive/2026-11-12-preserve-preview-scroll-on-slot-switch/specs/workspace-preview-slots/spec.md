## MODIFIED Requirements

### Requirement: 预览位可切换且状态独立
系统 SHALL 在顶部标签栏展示每个预览位，并在切换时恢复该位的文件、编辑模式、未保存修改、光标与选区、滚动位置、PDF 页码与大纲状态，以及适用的槽内焦点目标。Markdown 大纲持有焦点时，正文滚动位置与大纲焦点 SHALL 独立恢复。

#### Scenario: 切换预览位
- **WHEN** 用户点击某预览位标签
- **THEN** 系统激活该位并隐藏选中预览层
- **AND** 系统恢复该位适用的内容、模式、选区、阅读位置及槽内焦点
- **AND** 其他位的状态保持不变

#### Scenario: 切换工作区
- **WHEN** 用户离开工作区后再返回
- **THEN** 系统恢复该工作区的预览位列表、当前位及各位状态
- **AND** 恢复离开前活动面板和适用的面板内焦点

#### Scenario: 从目录面板键盘切槽
- **WHEN** current 面板持有焦点且用户用键盘切换预览槽
- **THEN** 活动槽改变，但目录焦点及已显示的选中预览层保持不变

#### Scenario: 从预览大纲切槽后返回
- **WHEN** 用户在 Markdown 或 PDF 大纲中切离预览槽，然后切回该槽
- **THEN** 系统恢复该槽的大纲焦点和有效的选中位置

#### Scenario: Markdown 大纲聚焦时快速往返切槽
- **WHEN** 用户将 Markdown 正文滚动到非顶部、大纲保持焦点，并快速切到另一预览槽再切回
- **THEN** 原槽正文保持切离前的阅读位置，大纲保持焦点和有效选中位置
- **AND** 另一槽的内容及阅读位置不受影响

#### Scenario: 缓存失效后切回
- **WHEN** 用户切回的 Markdown 槽需要因文件版本变化重新渲染
- **THEN** 系统在最终有效内容渲染完成后恢复适用的阅读位置
- **AND** 被取消或过期的渲染不覆盖该位置
