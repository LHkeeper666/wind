# PDF 连续滚动预览

## 背景

当前 PDF 预览面板采用单页模式：每次只渲染一页，通过 j/k 翻页切换。这种模式在浏览多页 PDF 时体验不佳——无法快速滚动浏览全文，也无法直观地看到上下文内容。

参考 Edge 浏览器的 PDF 查看器，改为连续滚动模式：所有页面纵向排列在可滚动容器中，虚拟化渲染可见页面，支持鼠标滚轮自由滚动。

## 改动范围

### 后端（Rust）

1. **扩展 `get_pdf_info`**：返回每页的 point 尺寸数组（当前只返回 page_count），用于前端计算占位高度
2. **新增 `get_pdf_outline`**：提取 PDF 内置书签（Outline/Bookmarks）的树形结构，包含标题、目标页码、精确坐标 (x, y)、缩放级别
3. **新增 `get_pdf_page_links`**：提取指定页的链接注解（Link Annotations），返回矩形区域 + 目标页码 + 目标坐标

### 前端（Svelte）

4. **重写 PdfPreviewPanel 渲染逻辑**：
   - 从单页 canvas 改为可滚动容器 + 虚拟化多页 canvas
   - 每页用占位 div 撑高度（高度 = pointHeight * scale）
   - IntersectionObserver 监听哪些页进入/离开视口，动态创建/销毁 canvas
   - PdfPageCache 复用，已渲染的 canvas 滚出缓冲区后销毁

5. **缩放重构**：
   - Ctrl + =/- 缩放（拦截防止全局缩放）
   - 缩放时先用 CSS transform 即时响应，后台异步重新渲染可见页的高清 canvas 替换
   - 缩放时同步更新所有占位 div 高度，保持滚动位置（视口中心对应内容不变）

6. **滚动位置 → 当前页码**：
   - 监听 scroll 事件，根据 scrollTop 计算当前视口中心所在的页码
   - 更新 info bar 的页码显示

7. **链接注解点击跳转**：
   - 后端提取每页的链接注解矩形区域
   - 在 canvas 上方叠加透明覆盖层（div），位置与链接区域对齐
   - hover 时 cursor: pointer，点击跳转到目标页的精确位置
   - 虚拟化时同步创建/销毁覆盖元素

8. **TOC 侧边栏**：
   - `:toc` 命令切换右侧 TOC 侧边栏显示/隐藏
   - 侧边栏展示 PDF 内置书签的树形结构，支持展开/收起
   - 点击条目滚动到目标页的精确位置（page offset + y * scale）
   - 当前可见页在侧边栏中高亮

9. **页码跳转**：
   - `:` 打开命令行，输入数字回车跳转到对应页
   - 滚动到目标页顶部

10. **快捷键调整**：
    - j/k：向下/上滚动一段距离（页面宽度未超出视口时生效）
    - h/l：向左/右平移（页面宽度超出视口时生效）
    - Ctrl+=/-：缩放（拦截，防止触发全局缩放）
    - g/G：滚动到顶部/底部
    - /：搜索（保留）
    - n/N：搜索跳转（保留，跨页）
    - 滚轮：垂直滚动
    - Ctrl+滚轮：缩放
    - Shift+hjkl 平移：移除（改用 h/l 原生滚动）

## 不在范围内

- 页面目录文本提取（从 PDF 前几页提取可点击目录文字）—— 实现复杂度高，后续考虑
- 文本选择层（Text Layer）—— 需要独立的文本覆盖层，后续考虑
- 全屏查看器适配 —— 全屏查看器保持当前单页模式，后续统一

## 验收标准

- [ ] 打开 PDF 后所有页面纵向排列，可自由滚动浏览
- [ ] 滚动流畅，只渲染视口附近 ±2~3 页，内存占用合理
- [ ] Ctrl+=/- 缩放即时响应，后台异步渲染替换，无明显卡顿
- [ ] info bar 显示当前视口中心所在页码
- [ ] PDF 内置书签在 TOC 侧边栏中正确显示，点击可跳转
- [ ] `:toc` 命令可切换侧边栏
- [ ] `:数字` 可跳转到指定页
- [ ] 链接注解可点击跳转到目标位置
- [ ] 搜索高亮跨页工作
- [ ] j/k/h/l/g/G 按预期工作
