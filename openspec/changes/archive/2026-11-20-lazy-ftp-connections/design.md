## Context

`FtpManager` 同时保存配置和主会话。当前 `connect` 在网络成功后才持久化，`disconnect` 同时移除会话与配置；`ftp_read_directory` 对所有列目录错误重连。编辑弹窗已区分 Save 与 Save and Reconnect，但传输各路径在持有管理器锁时调用 `create_independent`。现有 `edit-saved-ftp-connections` 规划及工作区实现是本变更的基础。

## Goals / Non-Goals

**Goals:** 离线可保存站点；所有 FTP 入口采用一致的按需建连规则；区分会话和站点生命周期；网络等待不阻塞配置操作；明确并发一致性。

**Non-Goals:** 改变 JSON 凭据格式、支持 FTPS/SFTP、站点重命名或取消已运行传输。

## Decisions

1. **配置与会话分离。** 增加 `:ftp add <name> <host[:port]> [--port N] [--user X] [--pass X]` 作为只保存入口，沿用现有参数默认值与重复名称校验。保留 `:ftp connect <name> <host...>` 的立即连接并导航体验，但先持久化新站点，再显式连接；连接失败仍保留站点并报错。`:ftp connect <name>` 对已保存站点显式确保连接并导航。选择新命令而非悄悄改变旧命令的意图，避免旧脚本失去立即连接行为。
2. **统一会话取得。** 远程导航、FTP 文件命令与操作前置查询均调用共同的 `ensure_session(name)` 路径：在短锁内取得配置快照和现有会话，锁外执行连接或必要的健康检查，再以配置版本/值校验后安装。并发首次访问按站点协调，避免重复建连覆盖；配置变化时丢弃旧建连结果并按新配置重试或返回明确错误。已有会话在配置普通 Save 后继续使用，显式重连成功才替换；断开时移除主会话，新请求可再按需建连。
3. **错误分类。** 目录读取保持 MLSD→LIST 回退。仅连接关闭、传输层故障或明确的会话失效证据触发一次重连并重试；目录不存在、权限不足、认证拒绝等非会话错误直接返回。无法可靠分类时先做有限健康检查：会话仍有效则返回原错误。避免对每个操作都无条件新建连接；重试最多一次。
4. **后台独立会话。** 任务开始时在短锁内复制当前已保存配置，锁外完成 TCP、登录和传输；不依赖主会话，也不将独立会话装入主会话表。运行中的任务继续使用启动时的快照；更新后的任务使用新配置。检查 `transfer/ftp.rs`、`move_group.rs` 和 `scheduler.rs` 的全部建连路径。
5. **分离断开与删除。** `:ftp disconnect <name>` 迁移为仅关闭/移除主会话，站点仍留在虚拟根目录；新增 `:ftp remove <name>` 显式删除配置并断开主会话。删除时处理正在建连的版本竞态，已运行传输不被中断。旧版依赖 disconnect 删除站点的用户需改用 remove；命令提示和反馈同步更新。
6. **持久化与并发。** 配置写入先校验并持久化候选映射，再更新内存；网络步骤不持有管理器锁。Save and Reconnect 先保存再在锁外连接，成功且配置未变时替换主会话；失败保留新配置及旧主会话。虚拟根目录仅读取配置，不触发网络。

## Risks / Trade-offs

- [旧 `disconnect` 的删除语义变化] → 命令提示明确 `remove` 迁移，并在规范中标记。
- [普通 Save 后旧主会话与新任务配置暂时不同] → 编辑提示说明，提供 Save and Reconnect。
- [误判连接故障导致重试副作用] → 仅明确失效时对可安全重试的目录读取重试；写操作不得在结果不明时自动重放。
- [并发建连与编辑/删除竞争] → 安装前比较配置快照，按站点协调建连，删除后不得恢复会话。

## Migration Plan

保持现有 JSON 格式和 `ftp://<name>/` 路径。发布时更新命令帮助与提示；旧 `:ftp disconnect` 删除用途改为 `:ftp remove`。回退版本可以读取原配置，但旧版 disconnect 仍会删除站点。

## Open Questions

无阻塞问题；实现时根据 suppaftp 错误类型确定失效分类细节，并以权限错误测试固定边界。
