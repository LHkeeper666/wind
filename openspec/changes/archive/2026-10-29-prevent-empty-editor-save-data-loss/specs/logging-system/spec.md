## ADDED Requirements

### Requirement: 文本保存操作具有可追溯诊断记录

系统 SHALL 对所有普通文本保存入口记录关联同一次操作的请求和结果，包含操作 ID、入口、目标路径、保存前磁盘大小、待写字节数、版本检查结果，以及成功、失败或拒绝原因。日志 MUST NOT 包含文件正文、密码或密钥内容。

#### Scenario: 成功保存

- **WHEN** 用户从编辑器保存文本且写入成功
- **THEN** 日志能以同一操作 ID 识别入口、路径、原大小、待写字节数与成功结果

#### Scenario: 拒绝异常空写

- **WHEN** 保存保护拒绝把异常空内容写入非空文件
- **THEN** 日志记录拒绝原因与相关元数据
- **AND** 不记录正文

#### Scenario: 磁盘版本冲突

- **WHEN** 保存时发现磁盘版本已在加载后改变
- **THEN** 日志记录版本冲突和未写入结果
