- [x] 2.1 为每个显示身份维护 `loading`、`ready`、`error`、`transition` 状态及对应文件大小、版本和草稿来源。

- [x] 2.3 检出未修改的非空文件对应异常空缓存后驱逐并重读，恢复目标文件元数据且不依赖修改时间改变。

- [x] 2.5 验证空缓存自愈、不同大小文件切换、零字节文件、读取失败和未保存空草稿。
