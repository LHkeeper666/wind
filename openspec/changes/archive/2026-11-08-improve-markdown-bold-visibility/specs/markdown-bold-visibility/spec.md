## ADDED Requirements

### Requirement: Markdown 预览清晰呈现加粗文本
系统 SHALL 在 Markdown 预览中以 700 字重及随主题变化的柔和强调色显示加粗文本，使其与相邻普通正文具有明显的视觉区别，同时不盖过标题层级。该要求适用于 Markdown 加粗语法生成的 `strong` 以及内嵌 HTML 的 `b`。

#### Scenario: 深色主题中的加粗正文
- **WHEN** 用户在深色主题下预览含有加粗正文的 Markdown 文件
- **THEN** 加粗文本具有比相邻普通正文更明显的字重和主题强调色

#### Scenario: 浅色主题中的加粗正文
- **WHEN** 用户在浅色主题下预览含有加粗正文的 Markdown 文件
- **THEN** 加粗文本具有比相邻普通正文更明显的字重和主题强调色

#### Scenario: 加粗与其他 Markdown 元素组合
- **WHEN** 加粗文本位于标题、链接、引用或表格中
- **THEN** 加粗文本仍可辨认，且所在元素的文本与背景保持可读

### Requirement: 三级和四级标题具有清晰层级
系统 SHALL 在 Markdown 预览中以字号和装饰区分三级与四级标题。三级标题 SHALL 显示短下划线，四级标题 SHALL 保持无下划线，且两者在深色和浅色主题下均可辨认。

#### Scenario: 相邻的三级和四级标题
- **WHEN** Markdown 预览中出现相邻的三级和四级标题
- **THEN** 三级标题的字号大于四级标题，并显示短下划线
- **AND** 四级标题不显示该下划线

#### Scenario: 标题与加粗正文同时出现
- **WHEN** Markdown 预览中同时出现三级标题、四级标题和加粗正文
- **THEN** 两级标题仍能凭借字号、间距及三级标题的短下划线被识别为结构性标题
