## MODIFIED Requirements

### Requirement: yank/delete 后粘贴使用本次内容

系统 SHALL 确保 `dd`、`yy`、`cc` 等 Vim 操作更新未命名寄存器后，随后的默认 `p/P` 粘贴本次操作内容。系统 SHALL 在从 PDF 或其他应用复制文本后，等待本次系统剪贴板读取完成再执行默认 `p/P`，不得使用过期缓存。显式指定寄存器时 SHALL 保持该寄存器的 Vim 粘贴语义。

#### Scenario: dd 后粘贴

- **WHEN** 用户执行 `dd` 删除一行
- **AND** 立即按下 `p` 粘贴
- **THEN** 粘贴出刚被 `dd` 删除的那行内容

#### Scenario: yy 后粘贴

- **WHEN** 用户执行 `yy` 复制一行
- **AND** 移动光标到其他行并按下 `p`
- **THEN** 粘贴出刚被 `yy` 复制的那行内容

#### Scenario: PDF 标签页复制后立即粘贴

- **WHEN** 用户在 PDF 标签页选择文本并按 `Ctrl+C`
- **AND** 切到已打开的 Markdown 编辑标签页并立即按 `p` 或 `P`
- **THEN** 粘贴本次 PDF 复制的文本，而非上一次剪贴板缓存

#### Scenario: 外部复制后粘贴

- **WHEN** 用户在其他应用复制文本并返回编辑器
- **AND** 立即按下默认 `p/P`
- **THEN** 粘贴本次系统剪贴板中的文本，无需等待 overlay 焦点刷新

#### Scenario: 系统剪贴板为空

- **WHEN** 系统剪贴板读取成功但内容为空
- **AND** 用户按下默认 `p/P`
- **THEN** 不粘贴上一次缓存的内容

#### Scenario: 系统剪贴板读取失败

- **WHEN** 系统剪贴板读取被拒绝或不可用
- **AND** 用户按下默认 `p/P`
- **THEN** 使用当前 Vim 寄存器行为回退，不注入过期缓存

#### Scenario: 显式寄存器粘贴

- **WHEN** 用户指定寄存器并执行 `"ap` 或 `"+p`
- **THEN** 粘贴由指定寄存器决定，默认剪贴板桥接不覆盖该选择

#### Scenario: 读取期间切换标签页

- **WHEN** 用户按下默认 `p` 后、剪贴板读取完成前切换到其他标签页
- **THEN** 待读取完成时不得将该内容粘贴到其他标签页或已失效的编辑器

#### Scenario: 连续按键顺序

- **WHEN** 用户快速连续输入默认 `p` 和后续 Vim 按键
- **THEN** Vim 按用户输入顺序处理这些按键
