# Wind v0.1.0

Wind's first release for Windows x64. The attached NSIS installer provides a Vim-style file workstation with a three-column browser, file previews, text editing, a floating terminal, and Wind's new application icon.

## Highlights

- Navigate files and panels from the keyboard, with adjustable column ratios, tabs, search, and a built-in shortcut reference (`F1`).
- Preview text, Markdown, JSON, images, PDFs, videos, archives, and directories. Edit text with CodeMirror 6 and Vim mode.
- Use a floating terminal with PowerShell, CMD, or Git Bash; manage files, the Recycle Bin, and local/FTP transfers.

## Download and requirements

Download `wind_0.1.0_x64-setup.exe` from the assets below and run it on Windows x64. Windows WebView2 is required; the installer handles its bootstrapper when needed. Video thumbnails require a separate FFmpeg executable available on `PATH` or via `WIND_FFMPEG_PATH`. Video playback depends on codecs supported by the embedded webview.

## Source and licenses
