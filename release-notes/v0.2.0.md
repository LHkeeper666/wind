# Wind v0.2.0

This Windows x64 release improves file browsing, previews, FTP connections, and transfer feedback, and includes several fixes since v0.1.0.

## What's new

- Edit saved FTP connections from the virtual root and connect to saved sites on demand.
- Follow Markdown anchors across files, view statistics for selected items, and see recent transfer speed.
- Keep copied files when a local paste encounters a name conflict; wrap selected filenames in the file list.

## Fixes

- Restore the active preview slot when reopening a file and correct Windows path completion in the command palette.
- Handle Unicode paths in the archive password cache, keep input dialog fields within their bounds, verify FTP cut moves before cleaning up the source, and display file timestamps in local time.

## Download and requirements

Download `wind_0.2.0_x64-setup.exe` from the assets below and run it on Windows x64. Windows WebView2 is required; the installer handles its bootstrapper when needed. Video thumbnails require a separate FFmpeg executable on `PATH` or configured with `WIND_FFMPEG_PATH`. Video playback depends on codecs supported by the embedded webview.
